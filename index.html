MidiTX Editor

MIDI editor for IK Multimedia TONEX Pedal. Control your pedal from your phone via Bluetooth (Android & iOS). Preset names: USB sync (Android) or import MidiTXPresets.json from a Mac (Android & iOS).

What it does

MidiTX Editor lets you control the TONEX Pedal from your phone—no need to bend down to the unit during rehearsals or on stage. You can:

  • Load preset names and settings so they appear in the app: on Android via USB sync (OTG cable) or by importing a file from a Mac; on iPhone/iPad by importing a file created on a Mac (see below). Both platforms support the same MidiTXPresets.json import.
  • Control the pedal via Bluetooth using a BLE MIDI adapter (e.g. midiA m-vave, M-VAVE MS1, or any compatible BLE MIDI dongle).
  • Switch presets (bank A/B/C) and edit parameters (amp, gate, comp, EQ, mod, delay, reverb) from the editor.
  • Save changes to the current preset and update the local cache so the app stays in sync.

How to use the app

Android

1. (Optional) Preset names You can sync preset names from the TONEX Pedal via USB (OTG cable): open the app, choose Start sync, connect the pedal, and wait for the sync to finish. Alternatively, you can import a preset list file (MidiTXPresets.json) created on a Mac using the tool below—tap Import preset list in the app and select the file. If you skip both, you can still control the pedal via Bluetooth; preset slots will appear as numbers.

iPhone / iPad

1. (Optional) Import preset list USB sync is not available on iOS. To have preset names in the editor, create a MidiTXPresets.json file on a Mac using the tool below, transfer it to your iPhone (AirDrop, Mail, iCloud Drive, etc.), then in the app tap Import preset list and select the file. If you skip this, you can still control the pedal via Bluetooth; preset slots will appear as numbers.
2. Connect via Bluetooth Enable Bluetooth, tap Scan, and pair/connect to your BLE MIDI adapter (the adapter must be connected to the TONEX Pedal’s MIDI input). The app looks for BLE MIDI devices only (e.g. midiA m-vave). Do not select “IK Multimedia ToneX” in the list—that is the pedal’s own Bluetooth; use your separate BLE MIDI dongle.
3. Use the editor After connecting, the editor opens. At the top you see the current preset (name if loaded, or slot index) and the bank (00–49) with three buttons (A, B, C). Tap a preset to switch it on the pedal. Use the Save button on the preset bar to save the current settings to the pedal and update the local cache. The tabs below let you adjust amp, gate, comp, EQ, modulation, delay, and reverb; changes are sent to the pedal in real time via MIDI.

Preset list: Mac tool (MidiTXPresets.json)

Use this tool on a Mac (with TONEX connected via USB) to create MidiTXPresets.json. You can then import the file in the app on Android or iOS (tap Import preset list and select the file). On iPhone/iPad this is the only way to load preset names; on Android it is an alternative to USB sync.

Binary for macOS Apple Silicon (M1/M2/M3). Not compatible with Intel. No installation required.

How to use:

  1. Download the file from the link above and save it to a folder (e.g. Desktop).
  2. Connect the TONEX Pedal to your Mac via USB.
  3. Open Terminal, go to that folder (e.g. cd ~/Desktop).
  4. Make it executable and run: chmod +x extract_presets_mac && ./extract_presets_mac
  5. The tool creates MidiTXPresets.json in the current folder.
  6. Transfer MidiTXPresets.json to your phone (AirDrop, Mail, cloud storage, USB, or Files app).
  7. In MidiTX Editor, tap Import preset list (MidiTXPresets.json) and select the file.

Optional: ./extract_presets_mac -o myfile.json to save under a different name or path.

Requirements

  • Android: Android 6.0 or higher. For USB sync: OTG cable and USB host support. Preset names can also be loaded by importing MidiTXPresets.json (Mac tool above).
  • iOS: iPhone or iPad with iOS 11 or higher. For preset names: Mac + the extract tool above to create MidiTXPresets.json, then import in the app.
  • IK Multimedia TONEX Pedal
  • For wireless control: a BLE MIDI adapter (e.g. midiA m-vave) connected to the pedal’s MIDI port

Privacy & data

No account or registration. All communication is between your phone and the pedal (Bluetooth or USB); no personal data is sent to our servers. The app may show ads; ad providers may collect data according to their policies.
